# TextForge Studio — 15 Client-Side Text, Writing & Content Tools

A zero-API suite of 15 browser-based text and writing utilities built with Next.js (App Router), React, TypeScript, and Tailwind CSS.

## Included Tools
1. Word & Character Counter
2. Case Converter
3. Remove Duplicate Lines
4. Bulk Find & Replace (with Regex)
5. Text Diff / Compare Checker
6. Lorem Ipsum / Dummy Text Generator
7. Reverse & Upside Down Text
8. Fancy Unicode Font Generator
9. Markdown to HTML & Live Previewer
10. URL Slug Generator
11. Text to Speech Reader (Browser Native)
12. Speech to Text Voice Typing (Browser Native)
13. Line Break & Extra Space Cleaner
14. Readability Score Checker (Flesch-Kincaid)
15. Name & Username Combiner

## Deploy on Vercel
Push this repository to GitHub and import it into Vercel. No environment variables or API keys required.
